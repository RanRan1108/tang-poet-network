# 唐代诗人社交网络与地理分布可视化

## 项目简介
本项目运用数字人文方法，对唐代主要诗人的社交关系与地理分布进行数据化整理与可视化呈现。通过构建诗人社交网络、绘制出生地分布图及个人游历路线图，探索唐代文学群体的互动模式与空间流动。

## 工具与技术
- **编程语言**：Python 3.13
- **数据处理**：Pandas
- **网络分析**：NetworkX
- **可视化**：Matplotlib
- **地理信息系统**：兰图绘
- **版本管理**：Git & Gitee

## 项目内容
### 1. 唐代诗人社交网络图
基于史料构建诗人交往数据集，使用 NetworkX 计算中心度，直观呈现李白、杜甫等人在诗坛的社交核心地位。

### 2. 诗人出生地分布图
收集主要诗人出生地经纬度，通过散点图展示唐代诗人地域分布特征。发现李白出生于西域碎叶城，地理上远离中原文化中心，却在社交网络中居于核心地位。

### 3. 诗人出生地交互地图
使用兰图绘在线地图工具，标注诗人出生地，提供可交互的地理信息展示。

### 4. 李白生平游历路线图
整理李白从出生到终老的重要地点，按时间顺序绘制其生平游历轨迹，展现这位伟大诗人跨越千里的传奇一生。

## 项目结构
- `?.py` — 诗人社交网络与出生地分布 Python 源代码
- `李白游历路线.py` — 李白游历路线图源代码
- `tang_poet_network.png` — 诗人社交网络图
- `tang_poet_birthplaces.png` — 诗人出生地散点图
- `李白游历路线图.png` — 李白游历路线图
- `大一点的大图.png` / `小一点的大图.png` / `具体位点.png` — 兰图绘交互地图截图

## 主要发现
李白的地理位置（碎叶城）与社交网络地位形成鲜明对比——地理上的“边缘人”，却是诗坛核心的“中心节点”。
